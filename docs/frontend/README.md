1. Đọc `frontend-tong-quan.md` để nắm kiến trúc và tiêu chuẩn chung.
2. Mở tệp chức năng tương ứng để triển khai UI, API, test.
3. Mỗi tệp có phần checklist và test case giúp xác nhận hoàn thiện.
